# Security Policy

## Reporting a vulnerability

Report suspected security vulnerabilities privately to
[security@basaltic.sh](mailto:security@basaltic.sh).

Please include the affected repository and version, a description of the issue
and its potential impact, and steps to reproduce it. A minimal proof of concept
or relevant logs can help us investigate. Remove credentials, private keys and
customer data from any material you send.

Do not disclose vulnerabilities through public issues, pull requests or other
public channels. Please coordinate disclosure with us while we investigate and
prepare a fix.
